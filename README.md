# TAMM for Render

نسخة TAMM المستقلة الجاهزة لـ Render. محتوى الاتفاقات والتسجيل الصوتي لا يُرسل إلى الخادم؛ الواجهة تسجل فقط معرّف جلسة عشوائياً لعداد الزيارات.

## الرفع

1. ارفع **محتويات هذا المجلد** إلى جذر مستودع GitHub.
2. في Render اختر **New > Blueprint** واربط المستودع، أو أنشئ Web Service يدوياً.
3. Build Command: `npm install && npm run build`
4. Start Command: `npm start`
5. أضف `DATABASE_URL` من قاعدة PostgreSQL الموجودة عندك في Render.

Render ينشئ جدول الزيارات تلقائياً عند أول تشغيل. الموقع يبقى عاملاً حتى من دون قاعدة بيانات، لكن عداد الزيارات يبقى صفراً.

## روابط

- الموقع: `/`
- الإحصاءات: `/insights-v7q2`
- فحص الخدمة: `/health`

## الخصوصية

- لا يتم إرسال محتوى الاتفاق أو الصوت أو مفاتيح التشفير إلى الخادم.
- رابط المشاركة مشفر بالكامل داخل جزء `#` من الرابط، وهذا الجزء لا يصل إلى الخادم.
- قاعدة البيانات تحفظ معرّف جلسة عشوائياً وتاريخ الزيارة فقط؛ لا تحفظ IP أو أسماء أو محتوى.
